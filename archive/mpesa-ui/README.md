# Archived M-Pesa UI

The dedicated M-Pesa workspace has been removed from the active app. These files preserve the last UI implementation for reference only:

- `index.html.snapshot` is a full snapshot of the app shell containing the M-Pesa home tile, workspace routes, markup, and styles.
- `bootstrap.js.snapshot` shows how the M-Pesa tools were attached to the app.
- `mpesa-tools.js` contains the transaction-tools screens and event handlers.

Nothing in this directory is imported, served, or compiled into the active web or Android app. The separate notification-listener implementation is archived in `../mpesa-notification-listener/`.
