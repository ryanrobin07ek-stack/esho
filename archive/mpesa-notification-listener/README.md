# Archived M-Pesa notification listener

This feature is archived and is not part of the active Vite or Android source sets. Do not move these files into `src` or `android/app/src/main/java` for a release unless notification-listener access has been reviewed and approved for the distribution channel.

The archive preserves the JavaScript Capacitor bridge, Android plugin, notification listener service, transaction parser, original Android manifest, and original `MainActivity` registration. The shipped app has no listener service declaration or plugin registration. POS mobile-money sales are recorded manually after the merchant verifies payment in the official M-Pesa app.
